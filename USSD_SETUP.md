\n# StockLink USSD — Africa's Talking Sandbox\n\nStockLink now exposes a real Africa's Talking-compatible callback:\n\n```text\nPOST /ussd\n```\n\nMenu:\n\n```text\nStockLink\n1. My balance\n2. Contribute R500\n3. Contribution history\n4. Group status\n5. Help\n```\n\nThe R500 payment rail is mocked for the hackathon, but confirming it writes the contribution to the real StockLink database, verifies it, updates the audit trail, and makes it visible in the Expo app.\n\n## 1. Install and run FastAPI\n\n```bash\ncd backend\npip install -r requirements.txt\nuvicorn app.main:app --reload --host 0.0.0.0 --port 8000\n```\n\nSwagger: `http://localhost:8000/docs`\n\n## 2. Test the USSD code locally\n\nOpen another terminal in `backend`:\n\n```bash\npython test_ussd.py\n```\n\nYou should see `CON` and `END` responses.\n\n## 3. Expose the backend using ngrok\n\n```bash\nngrok http 8000\n```\n\nIf ngrok gives you:\n\n```text\nhttps://abc123.ngrok-free.app\n```\n\nthen your callback URL is:\n\n```text\nhttps://abc123.ngrok-free.app/ussd\n```\n\nKeep FastAPI and ngrok running.\n\n## 4. Africa's Talking Sandbox\n\n1. Sign in to Africa's Talking.\n2. Open the Sandbox.\n3. Create/open a USSD channel.\n4. Set the channel callback URL to your `https://...ngrok.../ussd` URL.\n5. Save it.\n6. Open the Africa's Talking simulator.\n7. Register a simulator phone/session.\n8. Dial the sandbox USSD code shown by Africa's Talking.\n\nThe Sandbox works in Africa's Talking's simulator, not as a real handset shortcode.\n\n## 5. Live demo path\n\nDial -> choose `2` -> choose `1`:\n\n```text\nStockLink - Hi Lerato\n1. My balance\n2. Contribute R500\n3. Contribution history\n4. Group status\n5. Help\n```\n\n```text\nContribute R500 to\nUbuntu Savings Circle?\n1. Confirm\n2. Cancel\n```\n\n```text\nPayment verified!\nR500 recorded.\nRef: USSD-XXXXXXXX\n```\n\nRefresh the Expo app. The same contribution now appears in the shared ledger and audit trail.\n\n## Reset demo data\n\nIf August has already been paid, stop FastAPI, delete `backend/stocklink.db`, then restart FastAPI. The synthetic demo database will be seeded again.\n
